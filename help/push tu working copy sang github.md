# 📱 WORKING COPY (iPhone) → PUSH CODE LÊN GITHUB

## I. MỤC TIÊU
Thêm / sửa file trên iPhone → Commit → Push lên GitHub.

---

## II. QUY TRÌNH CƠ BẢN

### BƯỚC 1 — MỞ REPOSITORY
- Mở **Working Copy**
- Chọn đúng repo (ví dụ: `dtcs25_sstt`, `care_304`, ...)

### BƯỚC 2 — THÊM / SỬA FILE
Có thể:
- Create File
- Edit file trực tiếp
- Share file từ Files app vào Working Copy

### BƯỚC 3 — VÀO CHANGES
- Nhấn tab **Changes**
- Xem các file đã thay đổi
- Chọn file cần commit

### BƯỚC 4 — COMMIT
Nhấn **Commit**

Ví dụ commit message:
```bash
update from iphone
